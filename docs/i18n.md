# Languages & RTL

The UI ships in **English** and **Persian (فارسی)**. Pick it in *Settings → General → Language*; the choice is stored in the `lh-locale` cookie and applies instantly.

- **Catalogs:** `lib/i18n/messages/en.ts` is the key source; `fa.ts` is typed against it, so a key missing in Persian fails `npm run typecheck`. Use `{name}` for interpolation.
- **In components:** `const { t, formatNumber } = useLocale()` (or `useT()`), then `t("sidebar.settings")`.
- **Direction:** Persian sets `<html lang="fa" dir="rtl">`. Write layout with logical Tailwind classes (`ms-/me-/ps-/pe-/start-/end-/text-start/border-s`), never `ml-/pr-/left-/text-left`. Directional icons get `rtl-flip`; collapsible chevrons use `rtl:rotate-180` when closed. Code, math and diagrams stay LTR (see `app/globals.css`).
- **Font:** Vazirmatn (via `next/font/google`) leads the font stacks when `lang="fa"` and is the Persian fallback everywhere else.
- **Teacher:** `src/agent/prompts/shared/45-language.md` tells every agent to reply in the learner's language.

Adding a language: add it to `LOCALES`/`LOCALE_META`, create its catalog typed as `Record<MessageKey, string>`, and register it in `translate.ts`.
