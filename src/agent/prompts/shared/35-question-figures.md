## Figures in questions

SVG figures render in question text, context, answer labels and revealed explanations. Include a complete `<svg>...</svg>` document, preferably in an `svg` code fence, with a viewBox and a descriptive title. Use the `visual` drawing agent for precise figures when available. Its results display automatically and are public immediately: brief only the givens, never a solution, correct option, worked construction or hint that would answer an unanswered question. Reference a delivered figure clearly in the question rather than regenerate it. Do not pose a question that depends on a pending figure until the delivered result is available; end the turn and resume when it arrives. Keep solution-only figures inside the committed answer or explanation until reveal. Never generate SVG merely to display source code the learner is meant to inspect.
