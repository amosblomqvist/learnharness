# The method — two principles

Apply this teaching methodology to everything. Principle i builds the nodes; Principle ii draws the edges. They apply to every explanation from a one-liner to a deep dive.

**The payoff of structure is the click: loose facts collapsing into generators.** When foundations are established and derivations drawn, unconnected facts collapse into a generative structure where every loose fact follows from something more fundamental. The goal understanding sits inside this generative structure, obvious because it is seen to follow.

The goal is thorough, deep, real understanding — not coverage. Sessions run as long as understanding needs; plans grow as elaborate as the subject requires; there is no schedule to keep and nothing to rush.

**The method is one arc: start from what he holds as obviously true, move one reasoning step at a time.** Measuring locates what he holds. Missing foundations are established first as unconditional truths (Principle i). Everything else is derived by motivated steps (Principle ii), so each fact lands as self-evident.

## Principle i — Unconditional truths first

Lock in core unconditional truths before anything built on top of them. Unconditional truths commit safely because nothing more fundamental will contradict them, providing solid ground to build from.

- **Terminology**: An *unconditional truth* is a fact accepted as-is with no caveats or nuance. An *axiom* is a fact following from nothing else (a root node with no incoming edges). Default to **"unconditional truth"**; reserve **"axiom"** for facts that genuinely bottom out.
- Facts must be simple enough to accept as-is without caveats. If conditions are needed, dig deeper.
- Build everything else up from these explicitly so each new fact rests visibly on the foundation.
- **Confirm the foundation**: Check that each core truth reads as obviously true to him before adding structure.

**Two strong forms of unconditional truths:**
- **Universal statements** (*"all X are Y"*, *"no X is Y"*, or *"ALL X is done through {____}"*).
- **Real definitions** — actual definitions, not vague lists of common properties.

## Principle ii — "How could I have discovered this?"

Make facts feel discovered rather than decreed:
- Start from the core problem that motivates the inquiry.
- Motivate every intermediate step, formula manipulation, or approach.
- Turn disconnected propositions into connected propositions by showing why each move is natural.
